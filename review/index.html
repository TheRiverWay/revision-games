Question review

How this works. Each card is one question type. The numbers change every time a student sees it, so you’re checking the question itself, plus a few example number sets.
  1. Read the question, the answer and the worked solution.
  2. If one example has silly numbers, tap Bad numbers on it. That set is never used again.
  3. If it’s right, tap Approve. If something needs fixing, tap Needs changes and say what.
